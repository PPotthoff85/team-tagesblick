# Team-Tagesblick

Tagesübersicht für Patrick, Kirsten und Jan. Die Seite liest die Trello-Boards „Team – Aufgaben“ und „Kunden – Stand & Logbuch“ direkt im Browser, mit dem persönlichen Trello-Login der Person, die sie öffnet.

- Adresse: https://ppotthoff85.github.io/team-tagesblick/
- In dieser Datei stehen keine Kundendaten und keine Zugangsdaten. Der Trello-API-Schlüssel in `index.html` ist öffentlich und identifiziert nur die Seite.
- Ohne Trello-Zugang zu den Boards sieht man nur den Anmeldeknopf.
